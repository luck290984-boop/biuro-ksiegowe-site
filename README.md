# Kateryna Ivanova — biuro księgowe

Сайт-візитка бухгалтерського бюро: послуги, ціни, інформація про спеціалістку, запис на консультацію та контакти.
Мови сайту: українська, польська, російська (перемикач UA / PL / RU).

## Як відкрити

Двічі клікніть файл `index.html` — він відкриється у браузері. Інтернет не потрібен.

## З чого складається

- `index.html` — увесь сайт в одному файлі (текст, стилі, переклади, логотип і фото).
- `.gitignore` — список файлів, які ніколи не потрапляють у репозиторій (паролі, ключі, сертифікати).

## Важливо

- Контакти на сайті (телефон, e-mail, адреса) — справжні. Години роботи треба підтвердити перед публікацією.
- Форма запису на консультацію — демонстраційна: вона нікуди не надсилає дані.
- Не зберігайте в цьому проєкті паролі, токени, сертифікати KSeF і дані клієнтів.
